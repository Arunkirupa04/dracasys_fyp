NEXT STEPS: PHASE 2 - GRU TRAINING

After notebook completes:

1. Load sequences:
   ```python
   import numpy as np
   X_train = np.load('/content/drive/My Drive/.../sequences_horizon_1_X_train.npy')
   y_train = np.load('/content/drive/My Drive/.../sequences_horizon_1_y_train.npy')
   ```

2. Build GRU model:
   ```python
   import tensorflow as tf
   model = tf.keras.Sequential([
       tf.keras.layers.GRU(64, return_sequences=True, input_shape=(240, 34)),
       tf.keras.layers.Dropout(0.2),
       tf.keras.layers.GRU(32),
       tf.keras.layers.Dense(16, activation='relu'),
       tf.keras.layers.Dense(4)
   ])
   ```

3. Train model:
   ```python
   model.compile(optimizer='adam', loss='mse')
   model.fit(X_train, y_train, validation_data=(X_val, y_val), epochs=50)
   ```
